# 云上文旅集团干部管理制度 · 六环节细则员工版 · 总目录

## 一、这套细则是什么

这套细则是面向员工与机构负责人的干部管理实施细则，共 **12 件**，按干部在集团工作的六个环节排列，每环节两件：

- **流程件**：说清一件事从谁提出、谁做、做到什么程度、留什么记录。
- **工具件**：说清做这件事时用哪套方法、按什么步骤问、怎么记。

每件都可以单独阅读，不需要对照其他件。遇到「适用对象、时限、金额、编制」一类问题时，按件内写明的依据执行；这套细则未写明的，以集团其他现行规定为准。

## 二、六个环节

| 环节 | 这一段解决什么 | 环节内两件 |
|---|---|---|
| 一、招聘 | 持续找到适配的人，并把引荐变成可管理的日常动作 | 第01号 人才招聘与引荐（流程件、工具件） |
| 二、选用 | 用统一的评价维度和结构化程序把人选准，减少主观偏差 | 第02号 干部选用与评价（流程件、工具件） |
| 三、融入 | 让新任者尽快胜任、融入文化，早发现不适配 | 第03号 试用期与入职融入（流程件、工具件） |
| 四、发展 | 有计划地培养接班人，形成随时可用的后备梯队 | 第04号 中基层干部发展（流程件、工具件） |
| 五、保留 | 提前发现保留风险与继任缺口，把干部留住、把梯队做实 | 第05号 干部保留与激励（流程件、工具件） |
| 六、离任与洞察 | 交接不留断点、离任不带走组织知识、每次离任产生可用洞察 | 第06号 干部离任与洞察（流程件、工具件） |

## 四、怎么用这套细则

1. **先看流程件**：知道这件事归谁做、做到哪一步、留什么记录。
2. **再看同号工具件**：知道具体怎么做、用什么方法、记录怎么写。
3. **只看本环节两件即可**；需要跨环节衔接的地方，各件已写明输入来自哪个环节的哪份结论。
4. **这套细则没有规定的**，按集团其他现行规定执行；这套细则与集团其他现行规定不一致的，以现行规定为准。

## 五、适用与效力

这套细则是集团干部管理的基本制度。各件的具体规定与集团其他现行规定不一致的，以集团现行规定为准；集团另有更严规定的，从其规定。

# 本次干部管理制度整合·核心逻辑关键词（2026-11-07，供 PPT 用）

> 全部关键词从六件新制度（v5）工具总表与机判准绳现查核准，可直接上 PPT。

## 一、总框架（一句话逻辑）
以**干部全生命周期 6 环节**为主线，用**胜任力模型**统一标尺，配 **9 件专业工具**作判断层、**1 件通用载体**作留痕层，把 15 件旧细则收敛为 6 件新制度。

## 二、骨架关键词（按层级）

### 1. 主线：干部全生命周期 6 环节
招聘 → 选用 → 融入 → 发展 → 保留 → 离任（含洞察）

### 2. 统一标尺：胜任力模型
- 贯穿招聘画像、选用测评、发展评估的同一套维度
- 是 9 件工具的共同输入；评价维度/权重/门槛待模型定稿后填列

### 3. 判断层：9 件专业工具（按环节）
| 环节 | 专业工具 |
|---|---|
| 招聘 | ① 基于胜任力模型与岗位需求的人才画像　② 招聘渠道矩阵 |
| 选用 | ③ 基于胜任力模型的人才测评系统　④ 结构化面试 |
| 融入 | ⑤ 30-60-90 天融入计划 |
| 发展 | ⑥ 基于 SWOT 的个人评估　⑦ 基于 4P 的业务评估 |
| 保留 | ⑧ Gallup Q12 敬业度评估 |
| 离任 | ⑨ 5W 离职原因面谈 |

### 4. 留痕层：1 件通用载体
- **《干部全周期事项登记册》**（2026-11-07 拍板，单层）：统一承载节点事件、签认与日常事实，只引用、不随套交付
- 配套基准件（只引用不填报）：胜任力模型、岗位发展地图与能力差距对照表、原因编码字典、评分锚点

### 5. 整合方法论关键词（归纳整合的动作逻辑）
- 两类分工：**工具件**（写方法/结论/边界）＋**流程件**（写步骤/时点/负责人/留痕/签署）
- 四类处置：整合（重复待整合）、归纳（冗余待归纳）、删除（无效待删除）、新增（缺失待新增）＋第五类**移出**（整合不进去入旧件留档）
- 三条铁律：工具只引用不复制基准件词表；同一事实单一真源、他件只读引用；结论不回改已留痕事实

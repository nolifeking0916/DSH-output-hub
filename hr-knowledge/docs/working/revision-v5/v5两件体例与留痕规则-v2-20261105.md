## 一、两件分工（不重复的判法）

| | 《管理工具细则》 | 《管理流程细则》 |
|---|---|---|
| 回答什么 | **怎么测、怎么评、怎么用这个工具**（方法论）＋**对应哪些工具** | **谁在什么时间节点做什么、留什么痕**（行政流程） |
| 写什么 | 工具与方法总表（方法要点／使用时机／产出结论形式／不得越界项）；方法与流程节点对应；方法规则（步骤、标准、判断规则、结论形式、事实要求） | 适用范围与环节定位；行政流程表（步骤｜时间节点｜负责人｜留痕方式｜依据）；职责分工与衔接附则（含签署与归档） |
| **不写什么** | 不写留痕落点、不写谁签、不写档案存放处（属流程件） | 不写方法步骤与判断标准（属工具件）、不设评估流程表 |
| 章数 | 四章 | 三章 |

**归属判法（动笔前先问一句）**：这句话是"怎么做"，还是"谁在何时做、留什么痕"？前者进工具件，后者进流程件。

## 四、《修订说明》体例（v2：四类处置，直接表述）

每件一份（流程件＋工具件共用一份），按工具分块；每块四行处置：

```
# S1-吸引·修订说明（第01号《人才吸引与引荐细则》）

## 工具一　基于胜任力模型与岗位需求的人才画像
| 处置 | 原件或原附件 | 现在的形态 |
|---|---|---|
| 整合（重复待整合） | 《××》与《××》两处内容重复 | 合并为××，只留一处 |
| 归纳（冗余待归纳） | 原《××》第×节各项要求 | 归纳为×× |
| 删除（无效待删除） | 原《××》××表 | 不再设表，改为×× |
| 新增（缺失待新增） | 正本无×× | 新增×× |
```

规则：
- 四类处置**每块写全**；某类无内容时写「无（正本无此类内容）」，不许空着。
- 「现在的形态」写本 v5 的落点（哪件工具、哪个专页/栏/结论栏），**不写条号**。
- 来源只写**旧细则名或旧附件名**（节式正本不引章条号、不硬造）；件内多工具则分块写。
- 工具件与流程件共用同一份修订说明（不拆两份）——维护者要的是"这个管理工具"的来龙去脉。
- 篇幅：一件一块四行 × 工具件数，全文 ≤2 页。

## 五、留痕通则（两件都守，不越界到对方那层）

1. 事实只记一次；同一事实全流程一处留痕，他处只引用。
2. 结论必引事实；结论变化另注日期与依据，**不回改事实**。
3. **流程件**负责留痕方式与签署；**工具件**只写"须引用何类事实"，不写存哪、谁签。
4. 不设第 4 种工具；不预设备用表；不复制基准件词表（原因编码字典、十四条的正文只在真源处）。
5. 跨件引用只写制度全名、不引条号；任用结论一律"移送《干部发展管理细则（晋升任用与离任洞察）》"，不得出现任命/聘任/晋升决定字样。
6. 纯制度零数据：禁人数、编制数、比例%、职级码(M5/P5)、分值门槛(90/80/70、X分)、月数(X个月)、金额、内部系统名；一律「按集团现行规定／待胜任力模型定稿后填列」。
7. 不得替维护者裁：通用载体关系、法定专项去留、基准件清单、工具本体构成（4P 四项、5W 所指）、件号是否重排——正文留白。

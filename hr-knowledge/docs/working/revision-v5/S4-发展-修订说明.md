# S4-发展·修订说明（第04号《中基层干部发展细则》）

> 本件两个管理工具的修订，按「重复待整合／冗余待归纳／无效待删除／缺失待新增」四类处置说明，并列第五类「移出（整合不进去）」；来源只写旧细则或旧附件名，不引条号。

## 工具一　基于SWOT的个人评估

| 处置 | 原件或原附件 | 现在的形态 |
|---|---|---|
| 整合（重复待整合） | 原《中基层干部提升实施细则》与原《储备干部管理细则》中分散的学习与学时事实 | 合并为本件学习与学时登记、学习应用事实登记与两件评估方法的统一节点 |
| 归纳（冗余待归纳） | 原《中基层干部提升实施细则》培训赋能各款 | 归纳为学习包、年度计划、导师带教与应用事实登记的行政流程 |
| 删除（无效待删除） | 原学习应用记录载体 | 不再单设该载体，应用事实并入本件已留痕事实（载于《干部全周期事项登记册》） |
| 新增（缺失待新增） | 正本无个人评估方法 | 新增个人维度四格方法规则，不自评打分、只引已留痕事实 |

## 工具二　基于4P的业务评估

| 处置 | 原件或原附件 | 现在的形态 |
|---|---|---|
| 整合（重复待整合） | 原《挂职轮岗培养细则》任用发展考核要求中的业务复盘要求 | 合并为本件业务评估节点与业务维度方法，与个人评估分作两方结论 |
| 归纳（冗余待归纳） | 原《中基层干部提升实施细则》中业务落实与带教各款 | 归纳为业务维度评估与改进方向的结论形式 |
| 删除（无效待删除） | 原《管理干部双周工作汇报管理要求细则》（整件删除） | 该件不保留，其反馈事项改由上级月度审阅意见栏按月一次三段式承接 |
| 新增（缺失待新增） | 正本无业务视角评估方法 | 新增业务维度方法规则；四P构成与适用视角口径待上层裁定后填列 |

## 本件行政流程（非专业工具）

| 处置 | 原件或原附件 | 现在的形态 |
|---|---|---|
| 整合（重复待整合） | 原《干部工作日志与履职留痕细则》月度审阅意见栏与原《中基层干部提升实施细则》培养实施各款 | 合并为目标与业务结果对齐、学时与带教、学习应用事实登记、月度审阅意见、评估与结论移送各节点 |
| 归纳（冗余待归纳） | 原《中基层干部提升实施细则》适用范围与周期表述 | 归纳为适用范围与环节定位，层级范围与学时按集团现行规定 |
| 删除（无效待删除） | 原《中基层干部提升实施细则》中的评分门槛与期限数值 | 分值门槛与期限数值不再保留，改按集团现行规定或待胜任力模型定稿后填列 |
| 新增（缺失待新增） | 正本无月度审阅意见的三段式反馈规定 | 新增月度审阅三段式反馈节点，不作分数线、不回改事实栏 |

本件专业工具 2 件；通用载体与法定专项去留待维护者拍板；无第 4 种工具。

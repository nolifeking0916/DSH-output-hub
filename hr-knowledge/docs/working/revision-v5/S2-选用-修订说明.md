# S2-选用·修订说明（第02号《干部选用与评价细则》）

本件两个管理工具的修订，按「重复待整合／冗余待归纳／无效待删除／缺失待新增」四种处置说明；来源只写旧细则或旧附件名，不引条号。

## 工具一　基于胜任力模型的人才测评系统

| 处置 | 原件或原附件 | 现在的形态 |
|---|---|---|
| 整合（重复待整合） | 原《储备干部管理细则》《二、选拔标准》中分散的任职条件与后附评分锚点 | 整合为基于胜任力模型的人才测评系统一处施测，评分锚点降为基准件只引用不复制 |
| 归纳（冗余待归纳） | 原《储备干部管理细则》《二、选拔标准》中分列的年龄、学历、行业经验等条件 | 归纳为统一维度的测评方法；身份性条件不进正文，改为公平核查中的禁止性规定 |
| 删除（无效待删除） | 原《甄选评价记录》中混入的评分与结论栏 | 删除：测评结论只出在测评系统，过程事实另由登记事实承载，不混表 |
| 新增（缺失待新增） | 12 件现行正本无招聘件，无测评方法 | 新增基于胜任力模型的人才测评系统，测评结论作为选用综合研判依据之一 |

## 工具二　结构化面试

| 处置 | 原件或原附件 | 现在的形态 |
|---|---|---|
| 整合（重复待整合） | 原《甄选评分卡》中与测评结论重复的评级部分 | 整合为结构化面试一处独立评级，测评与面试分作两方结论 |
| 归纳（冗余待归纳） | 原各细则附件中零散的行为评价要求 | 归纳为统一题本、统一提问顺序与独立评价三步方法 |
| 删除（无效待删除） | 原《甄选评分卡》中按环节分设的多套评分件 | 删除：不按环节分设评分件，只保留一件方法与一处结论 |
| 新增（缺失待新增） | 正本无结构化面试的成文规定 | 新增结构化面试方法，行为事实与追问记录作综合研判依据 |

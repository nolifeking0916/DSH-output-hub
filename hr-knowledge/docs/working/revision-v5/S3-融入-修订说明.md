# S3-融入·修订说明（第03号《试用期与入职融入细则》）

> 以旧《管理层干部试用期考察管理细则》及其所附旧附件为来源，按四类处置直接表述；来源只写旧细则名与旧附件名，不引条号。

## 工具一　30-60-90天融入计划

| 处置 | 原件或原附件 | 现在的形态 |
|---|---|---|
| 整合（重复待整合） | 旧《试用期目标与考察记录表》与旧《试用期考核目标确认表》两处内容重复 | 合并为30-60-90天融入计划一个工具，阶段目标确认与节点达成判定各占一处 |
| 归纳（冗余待归纳） | 旧《管理层干部试用期考察管理细则》中考察内容与考察程序两项要求 | 归纳为三个节点各自的目标确认与达成判定方法，评价维度待胜任力模型定稿后填列 |
| 删除（无效待删除） | 旧《管理层干部试用期考察管理细则》中的评分档位、权重门槛与试用期限数值，以及旧《干部转正考察报告》 | 不再保留分值、权重与期限，改为按集团现行规定或待胜任力模型定稿后填列；期满考察结论改由本细则方法规则作出 |
| 新增（缺失待新增） | 正本无融入计划工具 | 新增30-60-90天融入计划，承载阶段目标、融入行动、节点达成判定与纠偏意见 |

## 本件行政流程（非专业工具）

| 处置 | 原件或原附件 | 现在的形态 |
|---|---|---|
| 整合（重复待整合） | 旧《管理层干部试用期考察工作方案》与旧《管理层干部试用期考察管理工作实施要求》 | 合并为行政流程的报到、目标与计划、阶段复核、预警处置、期满考察与结论移送各节点 |
| 归纳（冗余待归纳） | 旧《管理层干部试用期考察管理细则》中考察周期与适用范围两项表述 | 归纳为适用范围与环节定位，范围与期限按集团现行规定 |
| 删除（无效待删除） | 旧《管理层干部转正公示》与旧公示材料要求 | 不再在本件设置公示环节，相关办理统一移送《干部离任与洞察细则》 |
| 新增（缺失待新增） | 正本无预警处置与融入计划环节 | 新增预警处置行政节点与融入计划环节，节点时间、负责人与留痕方式写入行政流程 |

**本件工具计数（v5口径）：** 专业工具1件＝30-60-90天融入计划；通用载体关系与法定专项去留待维护者拍板；无第4种工具。

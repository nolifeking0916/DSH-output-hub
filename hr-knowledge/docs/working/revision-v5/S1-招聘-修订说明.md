# S1-招聘·修订说明（第01号《人才招聘与引荐细则》）

本件两个管理工具的修订，按「重复待整合／冗余待归纳／无效待删除／缺失待新增」四种处置说明；来源只写旧细则或旧附件名，不引条号。

## 工具一　基于胜任力模型与岗位需求的人才画像

| 处置 | 原件或原附件 | 现在的形态 |
|---|---|---|
| 整合（重复待整合） | 原《人才需求台账》与原《引荐登记册》两件表单中重复登记的岗位方向与需求事实 | 合并为一处岗位事实，随《干部全周期事项登记册》岗位视图承载，不另设两件表单 |
| 归纳（冗余待归纳） | 原《管理干部引荐人才要求细则》《一、总体目标》与《二、人才引荐要求》分列的引荐人数档位与有效性判定 | 归纳为岗位画像的硬性门槛与否决项；档位与期限指向集团现行规定，不进细则正文 |
| 删除（无效待删除） | 原《外部人才来源池》（前期留痕件，后已删） | 维持删除：候选人状态由各环节专页承载，本件不另设人才池 |
| 新增（缺失待新增） | 正本无岗位画像的成文规定 | 新增基于胜任力模型与岗位需求的人才画像方法，画像结论与依据索引作选用环节输入 |

## 工具二　招聘渠道矩阵

| 处置 | 原件或原附件 | 现在的形态 |
|---|---|---|
| 整合（重复待整合） | 原《人才需求台账》中的渠道投放记录与原《管理干部引荐人才要求细则》引荐渠道要求 | 整合为招聘渠道矩阵的一处渠道决策，投放记录与引荐事实不再分表 |
| 归纳（冗余待归纳） | 原《管理干部引荐人才要求细则》《一、总体目标》中对外渠道配置的表述 | 归纳为矩阵的四个比较维度（覆盖人群、成本、周期、匹配度）与选择理由 |
| 删除（无效待删除） | 原《管理干部引荐人才要求细则》《三、考核机制》所依赖的引荐达成考核台账 | 删除：引荐达成事实由本件登记，考核结论归集团现行绩效考核制度，不在本件另设台账 |
| 新增（缺失待新增） | 正本无渠道比较与选择的成文规定 | 新增招聘渠道矩阵方法，结论只反映渠道选择，不含招聘结果承诺 |

本件专业工具 2 件；通用载体关系与法定专项去留待维护者拍板；无第 4 种工具。
